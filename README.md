# Python-Data-Analysis

Conducted exploratory data analysis (EDA) on a large job-posting dataset to identify trends in job demand, salary distribution, remote-work opportunities, and geographic markets. • Performed data cleaning, missing-value analysis, aggregation, filtering, salary benchmarking, outlier detection, and group-level analysis using Python and Pandas. • Applied `groupby()`, `agg()`, `transform()`, ranking, and time-series analysis to derive actionable insights into high-demand and high-paying roles.
